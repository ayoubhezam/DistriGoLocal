# 1. Feature table

Part of [Distribute Pro compared with DistriGo](README.md).

"History" means the feature is listed in Distribute Pro's version history but was not seen on the phone, either
because its module is hidden on this install or because it sits behind the settings password.

## Both have

| Feature | Distribute Pro | DistriGo |
|---|---|---|
| Clients: list, search, phone call, photo, wilaya and commune, initial balance | Yes | Yes |
| Client GPS position and itinerary | Yes | Yes |
| Client payments (versements) and balance | Yes, with a printed receipt | Yes |
| Products: list, search, barcode scan, photo, purchase and selling price, stock | Yes, filter by famille | Yes, with catégories, sous-catégories and marques |
| Sales: draft or validated, edit, partial payment | Yes | Yes |
| Bluetooth ticket and PDF | Yes | Yes |
| Negative stock as a setting | Yes (history) | Yes, with a strict guard when it is off |
| Backup and restore | Yes (history) | Yes, plus Google Drive and automatic backups |
| Purchases, suppliers, supplier payments, inventory | History; hidden on this phone | Yes |
| Sales figures between two dates | One screen, by client | Six reports with drill-down to the records |

## Only Distribute Pro

| Feature | Note |
|---|---|
| Link to the desktop program | Pulls clients, products and company settings from the server. Pushes delivery notes and client payments over the local network (IP) or FTP, then lists them under « Bons de vente exportés ». |
| Colis entry on a sale line | The seller types the number of colis; N colis × colissage = quantity. Stock is shown in colis and in loose units (vrac). DistriGo stores units per colis on the product, but not on the sale line. |
| Remise on the note | As an amount or a percentage. |
| U.G (free units) | A column on each sale line. |
| Several tariffs | A « mode de tarif » per client. Only Prix 1 is in use on this phone. |
| TVA and HT prices | 0 % on the products seen. |
| Client fiscal fields and client code | R.C, A.I, N.I.F, N.I.S; the client code can be scanned as a barcode. |
| Map of all clients | Google Maps with one pin per located client. DistriGo has a map only inside a tournée. |
| Bons de commande (orders) | History, including import of orders from the server. |
| Locks for sales reps | A password on settings; switches that block price changes and note changes (history). |
| Product reference separate from the barcode | With a button that generates a code. |
| Time spent on each note | Shown on the note card. |

## Only DistriGo

| Feature | Note |
|---|---|
| Tournées | Secteurs and quartiers, clients per tournée, a map of the tournée. |
| Van stock separate from dépôt stock | Chargements move stock between the two. |
| Dashboard and Mon objectif | Daily figures and a sales goal. |
| Pertes, Retours, Charges, Mouvements | Losses, client and supplier returns with a reason per line, expenses, and a stock movement ledger. |
| Units and quantities | Carton, kg and pièce, with fractions for carton and kg. |
| Product details | Several barcodes per product, expiry dates, minimum stock. |
| Costs and margins | Cost by weighted average or last price, margin, price history. |
| Arabic interface | The whole app, right to left, chosen per phone. |
| Excel import and export | Products and clients. |
| WhatsApp receipts | |
| Corbeille | Deleted records can be restored. |
| Works alone | No PC or server is needed. |
